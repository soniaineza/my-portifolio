- **Frontend:** React, TypeScript, Tailwind CSS, Vue.js
- **Mobile:** Flutter, Dart
- **Backend:** Node.js, Python, Firebase
- **Databases:** MongoDB, SQLite, NoSQL, PocketBase
- **Tools:** Git/GitHub, IDX, VS Code, Figma (UI/UX Design)

- **INKINGI Rescue:** Real-time emergency response system.
- **WeOwn:** Modern real estate marketplace.

## 🛠️ Installation & Setup

To run this project locally:

1. Clone the repository: `git clone https://github.com/soniaineza/my-portifolio.git`
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
